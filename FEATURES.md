# Features

What the NEAR investment thesis does today, in plain words, and the test that proves each feature. This is the product's contract: change a row in the same pull request as the feature, and `./check` fails when a proof is missing. Planned work belongs in the plan, not here.

Proof names a test file and, after `#`, the name of the test inside it. Every proof names its test; a file alone is not a proof. The first proof is the feature's end-to-end test, and every end-to-end test must be named by some row. End-to-end tests live in `tests/*.e2e.test.mjs`: they run the real commands in a copy of the repository, offline and without keys, and read the pages those commands build. They do not open a browser. Several proofs are separated by commas.

| Feature | What it does | How to reach it | Proof | Broken looks like |
|---|---|---|---|---|
| Rebuild offline | Rebuilds `dashboard/` from the committed data in `data/public/`, with no network or keys, and checks every number in THESIS.md and docs/EVIDENCE.md against that data | Run `npm run rebuild` | `tests/product.e2e.test.mjs#npm run rebuild builds the dashboard offline from committed data`, `tests/public.test.mjs#rebuild CLI works offline, preserves prose and rejects inconsistent signer splits and stale metrics`, `tests/report.test.mjs#thesis metrics are verified, not rewritten; prose and tagged claims survive` | The command fails, asks for the network or a key, changes THESIS.md, or prints a metric mismatch |
| First screen | Shows the call "Not yet" and the three position checks with their results, and loads the script that fills a daily live line or keeps it hidden when its data is missing | Open `dashboard/index.html` | `tests/product.e2e.test.mjs#first screen shows the call, the three checks and the live line`, `tests/report.test.mjs#first-screen numbers match the published public-snapshot metrics`, `tests/live.test.mjs#first-screen live line reads same-origin live.json and hides when it is unavailable` | The call is missing, a check's number differs from docs/EVIDENCE.md, or the live line shows stale or broken text |
| Thesis page | Shows THESIS.md as a page, with its stated limits and links to the evidence, the model and the verification steps | Open `dashboard/thesis.html` | `tests/product.e2e.test.mjs#thesis page shows the thesis, its stated limits and its links`, `tests/report.test.mjs#thesis.html renders the real thesis without metric tags, escapes markup and keeps the CSP` | Raw Markdown or metric tags show, a limit sentence is gone, or a link is missing |
| 2031 supply model | Projects new supply, burn and buying to 2031 from measured inputs, with Bear, Base and Bull scenarios. The test computes the page's results in Node; it does not move the sliders | Serve `dashboard/` locally and open `model.html` | `tests/product.e2e.test.mjs#model page computes a 2031 result for the default and each scenario`, `tests/model-page.test.mjs#scenario buttons preserve exact sourced inputs through render, URL sharing and repeated preset changes`, `tests/model.test.mjs#calendar output covers exactly 2027–2031 and agrees with constant-cap closed-form issuance` | No 2031 row, "Not defined" for ordinary inputs, or scenarios that show the same result |
| Evidence beside the page | Publishes docs/EVIDENCE.md, the number tables, the verification steps and every chart next to the dashboard | Open `dashboard/docs/EVIDENCE.md`, `dashboard/NUMBERS.md` or `dashboard/VERIFY.md` | `tests/product.e2e.test.mjs#evidence, number tables and verification steps are published beside the page` | A missing file, a chart listed but not written, or a copy that differs from its source |
| Review command | Prints the data windows for a scheduled review date, offline and without keys, and refuses an unscheduled date | Run `npm run review -- 2027-02-01` | `tests/product.e2e.test.mjs#review command prints the windows for a scheduled review date offline`, `tests/review.test.mjs#review refuses unscheduled dates, malformed and conflicting flags` | The command needs the network or a key, prints the wrong window, or accepts an unscheduled date |
